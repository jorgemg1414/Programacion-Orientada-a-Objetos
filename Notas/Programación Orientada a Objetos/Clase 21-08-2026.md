# **¿Que es POO?**

Es un paradigma que ha ganado una Grand popularidad en los últimos años, debido a su capacidad para crear aplicaciones mas robustas, flexibles y fáciles de mantener  
  
Esta metodología de desarrollo se basa en la idea de que los programas se puede organizar como una colección de objetos interconectados cada uno con su propio conjunto de datos y funcionalidades

## Características principales

- Permite organizar los datos de sus programas al igual que los objetos que forman el mundo real
- Se fundamenta en el díselo de nuevas clases y objetos
- Los objetos contienen una serie de características y funciones asociadas
- Se pueden heredar las características o funciones mediante la herencia

## ¿Qué es un objeto?

Cuando un elemento es miembro de una clase se le llama objeto. Con frecuencia a los objetos se les llama instancias
